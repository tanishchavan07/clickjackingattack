What happened?

Clickjacking, also called UI Redressing, is an attack where a victim is tricked into clicking an interface element different from what they believe they are clicking.

Attacker Interface
       ↓
Deceptive/Invisible Overlay
       ↓
Target Buy Now Interface

How to Prevent Clickjacking

Use security headers such as:

X-Frame-Options: DENY
Content-Security-Policy: frame-ancestors 'self';

Authorization must still be enforced server-side because clickjacking protection does not replace access control.
